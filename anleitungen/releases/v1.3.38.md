# Anvil 1.3.38

Better Auth wurde von 1.6.30 auf die stabile Version 1.7.28 aktualisiert. Damit enthält Anvil die Korrektur für die mögliche Kontoübernahme über Magic Links und OAuth sowie die neueren Sicherheitskorrekturen der 1.7-Reihe. [Sicherheitshinweis CVE-2026-114607](https://github.com/better-auth/better-auth/security/advisories/GHSA-965c-763c-88jm)

Die Windows-Pakete starten mit deaktivierter Web-Anmeldung. Setup-EXE und portable ZIP für Windows x64 enthalten die benötigte Laufzeit. Das Setup ist unsigniert.

Bei eigenen Web-Deployments mit Generic OAuth müssen die beim Anbieter registrierten Rückleitungsadressen zum neuen Pfad `/api/auth/callback/<Provider-ID>` passen. [Upgrade-Leitfaden](https://better-auth.com/docs/guides/1-7-upgrade-guide#generic-oauth-is-rebuilt-on-the-social-provider-path)
