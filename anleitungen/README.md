# Anleitungen

Grundlage der Dokumentation: Release **1.3.29** vom **13.09.2026**. Beschriftungen und Erklärungen wurden am **22.09.2026** an den lokalen Entwicklungsstand angepasst; diese sprachlichen Änderungen sind noch nicht veröffentlicht. Ältere Praxistests bleiben mit ihrem jeweiligen Prüfdatum gekennzeichnet.

Windows: [Anvil 1.3.29](https://github.com/kokc866-hash/anvil/releases/tag/v1.3.29) — Setup-EXE oder portable ZIP. ZIP vollständig in einen beschreibbaren Ordner entpacken und `Anvil.exe` starten. Beide Pakete enthalten die Laufzeit; Node.js wird nur für die Arbeit am Quellcode separat benötigt. Das Release ist auf Wunsch des Eigentümers unsigniert.
